## ⚙️ How to Run (Step-by-Step)

### 1️⃣ Clone the Repository
Open your terminal and clone the project to your local machine:
```bash
git clone [https://github.com/jeel-detroja/faculty-profile-page.git](https://github.com/jeel-detroja/faculty-profile-page.git)
cd faculty-profile-page
```

### 2️⃣ Install Backend Dependencies
Navigate to the backend directory and install the required packages:
```bash
cd backend
npm install
```

### 3️⃣ Install Frontend Dependencies
Open a new terminal window, navigate to the frontend directory, and install its packages:
```bash
cd frontend
npm install
```

### 4️⃣ Start the Backend Server
In your backend terminal window, run:
```bash
npm start
```

### 5️⃣ Start the Frontend Application
In your frontend terminal window, run:
```bash
npm start
```

*(Note: Depending on your setup, the frontend will typically open automatically in your browser at `http://localhost:3000`)*
